# Cynthia Productions

Focused LMS at **cynthiamusic.com**: sell piano/composition courses to families. Brand is bright Sarasota beach — foam white, pale aqua sky, gulf `#2BBCD0`, sunset coral for buy buttons. Mark is a coral sun over piano keys as a gulf wave. Big type, large pill buttons, 2rem rounded cards. Fonts: Fraunces + Source Sans 3. Logo options live at `/brand` (noindex).

Do not port the old WordPress catalog (musicals, novels, VBS). Do not copy Misty Barron’s lavender/gold palette.

Admin screens are full-width workbenches (`AdminPage`). Never wrap admin in `max-w-*`.
